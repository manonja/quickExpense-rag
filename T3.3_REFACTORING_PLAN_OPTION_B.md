## Executive Summary

This plan eliminates architectural debt by refactoring the extraction pipeline to use the canonical `src/qe_tax_rag/extraction/ca/orchestrator.py:run_extraction()` function instead of script-level business logic.

**Strategy**: Two-phase TDD approach using an **adapter pattern**:
- **Phase 1**: Convert `_run_extraction_pipeline()` into a thin adapter that calls the canonical orchestrator
- **Phase 2**: Update `pipeline-extraction` to call the orchestrator directly, breaking script-to-script dependency

**Principles Applied**:
- ✅ **80/20**: Minimal refactoring for maximum architectural improvement
- ✅ **YAGNI**: Keep adapter for backward compatibility, don't over-engineer
- ✅ **TDD**: RED-GREEN-REFACTOR cycle with 6 atomic commits
- ✅ **Simplicity**: Clear interface mapping via adapter pattern

2. **Rewrite `_run_extraction_pipeline()` as adapter**:
```python
def _run_extraction_pipeline(
    html_files: list[Path],
    output_yaml: Path,
    manual_review_yaml: Path,
    output_jsonl: Path | None,
    verbose: bool = False,
) -> tuple[dict, "TransformationReport | None"]:
    """
    Adapter for core extraction pipeline.
    Calls canonical orchestrator and adapts output to legacy format.
    """
    if verbose:
        logging.getLogger().setLevel(logging.DEBUG)

    # Orchestrator expects a path, not list of files
    if not html_files:
        return {}, None
    input_dir = html_files[0].parent

    # 1. Call canonical orchestrator
    result = run_extraction(
        input_path=input_dir,
        output_yaml=output_yaml,
        manual_review_yaml=manual_review_yaml,
    )

    # 2. Adapt new structure to old flat stats dict
    stats = {
        "total_rules": result["total_rules"],
        **result["stats"],  # perfect_matches, auto_corrected, manual_review
    }

    # 3. Handle transformation (orchestrator doesn't do this)
    transformation_report = None
    if output_jsonl is not None:
        transformer = YAMLTransformer()
        transformation_report = transformer.transform_yaml_to_jsonl(
            yaml_path=output_yaml,
            jsonl_path=output_jsonl,
            continue_on_error=True,
        )

    return stats, transformation_report
```

### Canonical Orchestrator (run_extraction)
```python
def run_extraction(
    input_path: Path,                # Takes path (file or dir)
    output_yaml: Path,
    manual_review_yaml: Path,
    dry_run: bool = False,           # No auto-transform
) -> dict[str, Any]:
    # Returns nested dict:
    # {
    #     "total_files": X,
    #     "processed_files": Y,
    #     "failed_files": [(name, error), ...],
    #     "total_rules": Z,
    #     "stats": {
    #         "perfect_matches": A,
    #         "auto_corrected": B,
    #         "manual_review": C,
    #     },
    #     "manual_review_count": D,
    # }
```

### Adapter Implementation
```python
def _run_extraction_pipeline(...) -> tuple[dict, TransformationReport | None]:
    # 1. Call orchestrator
    result = run_extraction(input_path=html_files[0].parent, ...)

    # 2. Adapt structure (nested → flat)
    stats = {
        "total_rules": result["total_rules"],
        **result["stats"],
    }

    # 3. Handle transformation separately
    report = None
    if output_jsonl:
        report = YAMLTransformer().transform_yaml_to_jsonl(...)

    return stats, report
```
