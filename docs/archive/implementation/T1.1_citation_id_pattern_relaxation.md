## Implementation Notes

### Pattern Details

Both patterns use anchors (`^` and `$`) to ensure exact matching:

- **Legacy**: `S\d+-F\d+-C\d+-p\d+\.?\d*` - Allows optional decimal part
- **LINE**: `LINE-\d+` - Requires uppercase LINE prefix followed by digits
- **Case-sensitive**: LINE must be uppercase
- **No whitespace**: Leading/trailing spaces rejected
