## Key Improvements

### 1. Adapter Pattern

Created `_run_extraction_pipeline()` as thin adapter that:

- Calls canonical `run_extraction()` from src package
- Adapts nested output structure to flat stats dict
- Handles transformation separately (YAML → JSONL)
- Maintains backward compatibility for `extract-rules` CLI

### 2. Direct Orchestrator Calls

`pipeline-extraction` command now:

- Calls `run_extraction()` directly (no script-to-script dependency)
- Clearly separates extraction and transformation steps
- Eliminates architectural debt

### 3. Clean Imports

All imports now follow src-layout pattern:

```python
from qe_tax_rag.extraction.ca.orchestrator import run_extraction
from qe_tax_rag.extraction.ca.transformer import YAMLTransformer
```
